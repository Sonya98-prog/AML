# AML Академия — платформа обучения по COMITA AML

Корпоративная обучающая платформа АО «Комита»: курс для продуктовых аналитиков и РП по системе COMITA AML — домен ПОД/ФТ, 115-ФЗ, 11 функциональных компонентов, ЭДО с регуляторами, лицензирование и миграция.

**Статическая версия** — работает на GitHub Pages без сервера: вход в аккаунт не нужен, а прогресс (зачёты, результаты тестов) сохраняется в браузере устройства (localStorage).

## Возможности

- **Без регистрации** — открыл сайт и учишься
- **Прогресс в браузере** — зачтённые занятия, история попыток тестов, средний балл; хранится локально на устройстве (при очистке истории браузера прогресс обнулится)
- **18 занятий в 7 блоках** — концепция, схемы, разбор кейсов, 78 вопросов практики с фидбеком, мини-проверки блоков (порог 70%)
- **Глоссарий 53 термина** с поиском
- **Варианты ответов перемешиваются** при каждой попытке

## Технологии

Next.js 16 (App Router, static export) · TypeScript · Tailwind CSS 4 · shadcn/ui · localStorage

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Публикация на GitHub Pages

Деплой автоматический: при каждом пуше в `main` срабатывает workflow `.github/workflows/deploy.yml` — сайт собирается и публикуется по адресу `https://<логин>.github.io/<репозиторий>/`.

Один раз в настройках репозитория: **Settings → Pages → Source = GitHub Actions**.

## Где что лежит

| Путь | Что это |
|---|---|
| `src/content/course-data.json` | **Весь контент курса**: блоки, уроки, кейсы, вопросы, схемы (SVG), глоссарий, источники |
| `src/lib/course.ts` | Типы контента и правила (пороги зачёта, порядок уроков) |
| `src/lib/local-progress.ts` | Хранение прогресса в браузере (localStorage) |
| `src/app/page.tsx` | Дашборд участника |
| `src/app/lesson/[id]/` | Страница занятия (все уроки собираются статически) |
| `.github/workflows/deploy.yml` | Автодеплой на GitHub Pages |

### Как отредактировать урок

Откройте `src/content/course-data.json` и найдите урок по `id` (например, `"2.2"`). Внутри: `concept` (абзацы, таблицы, списки, коллауты, схемы), `case` (кейс), `practice` (вопросы: текст, варианты, фидбек `fb`, флаг правильного `ok`), `summary` (запомнить), `isCheck` (мини-проверка блока). После правки сохраните — в dev-режиме всё применится сразу, после `git push` обновится и опубликованный сайт.
