# AML Академия — платформа обучения по COMITA AML

Корпоративная обучающая платформа АО «Комита»: курс для продуктовых аналитиков и РП по системе COMITA AML — домен ПОД/ФТ, 115-ФЗ, 11 функциональных компонентов, ЭДО с регуляторами, лицензирование и миграция.

Полноценное веб-приложение с аккаунтами: прогресс каждого сотрудника, результаты тестов и зачёты хранятся в базе данных, а не в браузере. Ментор видит индивидуальную статистику всей команды.

## Возможности

- **Личные аккаунты** — регистрация и вход; первый зарегистрированный аккаунт автоматически получает роль **ментора**
- **Индивидуальный прогресс** — зачтённые занятия, история попыток тестов, средний балл (в SQLite)
- **Дашборд ментора («Команда»)** — прогресс каждого участника: % курса, баллы по 7 блокам, активность; выгрузка в CSV
- **18 занятий в 7 блоках** — концепция, схемы, разбор кейсов, 78 вопросов практики с фидбеком, мини-проверки блоков (порог 70%)
- **Глоссарий 53 термина** с поиском
- **Варианты ответов перемешиваются** при каждой попытке

## Технологии

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · Prisma + SQLite · аутентификация на HMAC-сессиях (cookie), пароли — scrypt

## Быстрый старт (VS Code)

Нужен Node.js 20+ или [Bun](https://bun.sh). Рекомендуется Bun.

```bash
# 1. Установить зависимости
bun install        # или: npm install

# 2. Создать базу данных (SQLite)
bun run db:push    # или: npx prisma db push

# 3. Запустить
bun run dev        # или: npm run dev
```

Откройте http://localhost:3000 и зарегистрируйте первый аккаунт — он станет менторским.

## Где что лежит

| Путь | Что это |
|---|---|
| `src/content/course-data.json` | **Весь контент курса**: блоки, уроки, кейсы, вопросы, схемы (SVG), глоссарий, источники |
| `src/lib/course.ts` | Типы контента и правила (пороги зачёта, порядок уроков) |
| `src/app/page.tsx` | Дашборд участника |
| `src/app/lesson/[id]/` | Страница занятия |
| `src/app/team/` + `src/app/api/team/` | Дашборд ментора |
| `src/lib/auth.ts` | Сессии и пароли |
| `prisma/schema.prisma` | Модель данных: User, LessonProgress, QuizAttempt |
| `db/custom.db` | База данных (создаётся автоматически) |

### Как отредактировать урок

Откройте `src/content/course-data.json` и найдите урок по `id` (например, `"2.2"`). Внутри: `concept` (абзацы, таблицы, списки, коллауты, схемы), `case` (кейс), `practice` (вопросы: текст, варианты, фидбек `fb`, флаг правильного `ok`), `summary` (запомнить), `isCheck` (мини-проверка блока). После правки сохраните — в dev-режиме всё применится сразу.

## Продакшен-деплой

SQLite — файловая БД, поэтому платформу удобно ставить на VPS или в контейнер (Vercel не подойдёт — там нет постоянного диска):

```bash
bun run build
bun run start     # порт 3000; за nginx/caddy — по ситуации
```

Не забудьте: `AUTH_SECRET` в `.env`, регулярный бэкап `db/custom.db`.
